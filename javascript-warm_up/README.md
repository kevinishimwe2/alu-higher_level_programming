# JavaScript Warm-Up

## Introduction to JavaScript

Welcome to the JavaScript Warm-Up module! This section covers fundamental concepts to get you started with JavaScript programming.

## Topics Covered

- **Variables & Data Types** - Learn about `var`, `let`, `const` and primitive types
- **Operators** - Arithmetic, logical, and comparison operators
- **Control Flow** - Conditionals (`if`, `else`, `switch`) and loops (`for`, `while`)
- **Functions** - Function declaration, arrow functions, and scope
- **Arrays & Objects** - Working with collections and data structures
- **String Manipulation** - String methods and template literals
- **Basic DOM Interaction** - Selecting and manipulating HTML elements
- **Callbacks & Promises** - Introduction to asynchronous JavaScript

## Getting Started

1. Read through each concept file
2. Study the code examples
3. Practice with the exercises
4. Test your understanding with mini-projects

## Prerequisites

- Basic programming knowledge
- A text editor (VS Code, Sublime Text, etc.)
- Node.js or a modern web browser
